# naisurf

温馨可爱、像素伪 3D 的原创冲浪小游戏。包含无尽浪潮、计时试炼、发夹弯、奶滴收集四种模式，以及五名可选角色、奶鲨追逐、渔网捕获和离线 PWA。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 操作

- 电脑：`A/D` 转向，`W/S` 加减速，`F` 冲刺，空格暂停，`Esc` 打开暂停菜单。鼠标、方向键和手柄不控制轨迹。
- 手机：按住左半屏向左、右半屏向右；底部按钮用于加速、刹车和冲刺。

## 核心规则

- 所有模式和难度固定 5 条命，没有接触不会掉血。
- 撞障碍扣 1 命，任何奶怪接触扣 2 命并使当前奶怪停止追击。
- 未碰撞时，进入约半个冲浪板宽的距离会触发奶怪追击。
- 渔网只在追击中出现；奶怪距离小于 24 米时贴网掠过即可捕获当前奶怪并获得 10 奶币。
- 黄色“+”光环是增益，紫色“−”菱形是黏奶泡减速，珊瑚红“!”角标代表障碍。

游戏成绩、奶币、角色解锁、规则阅读状态和设置保存在浏览器本地，不会上传服务器。
