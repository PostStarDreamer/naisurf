# naisurf

温馨可爱、像素伪 3D 的原创冲浪小游戏。包含无尽浪潮、计时试炼、发夹弯、奶滴收集四种模式，以及五名可选角色、奶怪追逐、渔网捕获和离线 PWA。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 操作

- 键盘：方向键或 WASD 转向与加减速，`F` / `Shift` 冲刺，空格暂停。
- 触屏：在游戏画面拖动转向，右下角按钮刹车与冲刺。
- 手柄：左摇杆或十字键转向，扳机加减速，A 键冲刺。

游戏成绩、奶币、角色解锁和设置保存在浏览器本地，不会上传服务器。
