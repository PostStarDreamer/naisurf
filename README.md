# naisurf

温馨可爱、像素伪 3D 的原创冲浪小游戏。包含无尽浪潮、计时试炼、发夹弯、极限模式，以及五名可选角色、奶鲨追逐、统一奶币事务、渔网捕获、奶币复活、高清角色素材、分层音乐音效和离线 PWA。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

## 操作

- 电脑：`A/D` 转向，`W/S` 加减速，`Shift` 冲刺，空格暂停，`Esc` 打开暂停菜单。鼠标、方向键和手柄不控制轨迹。
- 手机：按住左半屏向左、右半屏向右；画布下方独立控制栏用于加速、刹车和冲刺。

## 核心规则

- 所有模式和难度固定 5 条命，没有接触不会掉血。
- 撞障碍扣 1 命，任何奶鲨接触扣 2 命并使当前奶鲨停止追击。
- 未碰撞时，横向进入约 `0.62` 的感应范围会触发奶鲨追击。
- 渔网只在追击中出现；奶鲨距离小于 24 米时贴网掠过即可捕获当前奶鲨并立即获得 10 奶币。
- 速度会随单局时间持续提高，没有固定上限；障碍、道具和奶鲨会更快逼近，背景海浪保持固定节奏。
- 触控设备的障碍行间隔比电脑长 12%，困难与地狱的 4 障碍行更少，但仍保留至少 0.44 宽、可达的安全通道。
- 发夹弯连续穿门时，漏过浪门会立即结束本局，不扣生命；最终成绩取本局最高连门数。
- 游戏内只显示巡航、加速、刹车或冲刺状态，不显示难度、速度倍率或升档提示。
- 奶滴、满血爱心和捕获奖励会立即写入永久奶币；距离奖励在结算时统一发放。
- 所有奶币、复活和角色解锁操作使用唯一事务 ID，重复事件不会再次加减余额。
- 普通模式每局最多复活 3 次，费用依次为 100、200、300 奶币，复活后恢复 3 条命并获得 1 秒保护。
- 极限模式生命耗尽即结束，不能复活。
- 角色解锁价格依次为奶鼠 180、奶鸡 400、奶狗 750、奶蛙 1200，同时要求累计局数和捕获数；已解锁角色永久保留。
- 奶鲨在潜伏、追赶、捕获和主界面分别使用附件中的 front 3/4、front、back 3/4 和 side view。
- 奶鲨追击从 30 米开始，拉开到 72 米可脱离；速度增长和黏奶泡会让追击压力继续上升。
- 黄色“+”光环是增益，紫色“−”菱形是黏奶泡减速，珊瑚红“!”角标代表障碍。
- 主页自动尝试循环《L'océan — Richard Clayderman》（用户提供并授权）；被浏览器拦截时可点顶部“开启音乐”。进入游戏后淡出到原创分层配乐，全部音频支持 PWA 离线缓存。
- 主页面顶部提供自愿打赏入口，完整展示用户提供的赞赏码，不接入支付 SDK。

游戏成绩、奶币、角色解锁、规则阅读状态和设置保存在浏览器本地，不会上传服务器。

## 公开反馈信箱

- 主页反馈入口会生成带 `feedback` 标签的公开 GitHub Issue；玩家需要登录 GitHub，请不要填写敏感信息。
- `npm run feedback:install` 安装每天 `00:05` 的本地导出任务，自动读取仓库中尚未导出的 `feedback` Issue。
- 每日随机选择最多 5 条，按日期追加到 `D:\FILES\AI generated\奶浪冲浪祭反馈信箱.txt`，并保留最近 30 个日期区块。没有未导出反馈时不改动文件。
- 可用 `npm run feedback:export` 手动导出，或运行 `tools/install-feedback-tasks.ps1 -Uninstall` 移除导出任务。
